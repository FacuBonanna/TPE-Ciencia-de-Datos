# Trabajo pŕactico especial: Fundamentos de la ciencia de datos 

Como parte de la propuesta de la cátedra "Fundamentos de la ciencia de Datos" realizamos un cuaderno de jupyter donde respondimos a un conjunto de consignas especificas. 
En este repositorio encontrarán el cuaderno de jupyter con los códigos y comentarios que validan el análisis que hicimos en el informe de respuesta (que también se encuentra en el repositorio) 

## ¿Cómo probar el trabajo? 

  paso 1: activar el entorno de jupyter notebook en su visualizador de código de elección. 

  paso 2: descargar todos los requerimientos utilizando el siguiente comando (que debe ser ingresado por consola) 

  pip install -r requirements.txt
  
  paso 3: probar el cuaderno y ejecutar sus secciones de código. 

  nota: si falla la descarga de requerimientos, se deberá descargar cada dependencia de forma manual utilizando el comando pip install según lo requiera el código.
